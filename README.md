## AsureTraits

Плагин, добавляющий возможность присваивать игрокам свойства или черты, выполняющие различные функции (механики). В зависимости от цели,
свойства могут представлять собой как стандартную систему перков или присваиваемых черт характера персонажей, так и продвинутую
систему рас или профессий с возможностью прогресии.\
Для функционирования многих базовых механик требуется плагин **MythicMobs**.

---

## Модули и возможности

- **Свойства (AsureTrait)**: Механики, выполняющие определённые действия или функции. Могут быть присвоены игроку командой, 
либо же могут быть выбраны игроком самостоятельно через GUI свойств.
- **Очки свойств (Cost)**: Используются для ограничения выбираемых игроком свойств. Задаются в конфиге свойства. В стандартном применении
используются для мотивации игрока выбирать отрицательные свойства вдобавок к положительным.
- **Теги свойств**: Свойствам могут присваиваться теги, которые могут являться условиями, ограничивающими получение других свойств через GUI.
- **Связанные свойства**: В конфиге свойств могут быть заданы связанные свойства, которые будут выданы вместе с основным свойством. Подобная связка позволяет
реализовать концепцию наборов свойств (например, для использования системы свойств в качестве системы рас или профессий).
- **Применяемые механики**: Некоторые механики могут быть применены нажатием на клавишу определённого действия (ЛКМ, ПКМ, Смена руки, Выбрасывание предмета, Прыжок).
Для таких механик игрок может самостоятельно назначить бинд.
- **Плейсхолдеры свойств**: Интеграция с PlaceholderAPI. Любое свойств или тег свойств может быть преобразовано в плейсхолдер,
в котором будет содержаться отображаемое название свойства.
- **Создание кастомных механик**: Плагин основан на принципе модульности механик. Любой плагин, наследующий данный, может
стать аддоном, добавив собственные механики.
- **Хранение данных**: Свойства игроков хранятся в базе данных MySQL при помощи фреймворка JDBI. Подобный формат позволяет
игроку иметь одни и те же свойства на разных серверах одного проекта.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib (VineriumLib). Путь до артефакта должен
выглядеть следующим образом относительно папки проекта: `../VineriumLib/build/libs/VineriumLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
